A program that writes one one-line pickup line for a robot or an AI for
make.fun to `/output/entry.txt`, for the make.fun competition
[Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa).

The line plays on two AI-native words at once: a hallucination is what an
AI invents, and being grounded is what pulls it back to reality, so loving
the machine means never wanting to be pulled back.

## Run it

```sh
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 68 characters, inside the 1 to 200 gate, and
exactly one line.

## The entry

```
If loving you is a hallucination, I never want to be grounded again.
```
